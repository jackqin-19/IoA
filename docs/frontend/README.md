### 🚀 快速开始

```bash
cd im_server/frontend
npm install
npm start
```

访问：http://localhost:3000

### 📁 改造文件

所有前端改造涉及的文件都在 `im_server/frontend/` 目录下：
- `src/index.css` - 设计系统基础
- `src/App.css` - 整体布局
- `src/components/GroupList/` - 团队列表组件
- `src/components/ChatWindow/` - 聊天窗口组件
- `src/components/Message/` - 消息组件
- `public/index.html` - 页面元信息
